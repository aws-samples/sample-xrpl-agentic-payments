Why This Exists

Today, cross-border payments at financial institutions move through 5 separate teams and systems — compliance review, foreign exchange, route selection, payment submission, and reconciliation. Each step involves human intervention, business-hour constraints, and days of latency.

AI agents can execute these same steps in seconds — with full transparency, governance, and audit trails — while humans retain control over policies, thresholds, and signing authority.

This prototype proves it works. Real transactions. Real settlement. Real compliance screening. On a public blockchain network that settles in 3-5 seconds.

What It Does — The Agent Workflow

The prototype mirrors the exact workflow banks already follow for cross-border payments — but replaces manual steps with AI agents, each with strictly scoped permissions:

Deterministic sequencing: The five agents are invoked in this fixed order by a plain Python function (run_multi_agent_payment) running inside the web application. There is no LLM supervisor deciding the order, and no single agent performs all five steps.

Security by design: Each agent can ONLY access its own tools. The Compliance Agent cannot execute payments. The Execution Agent cannot skip compliance. If any agent is compromised, it cannot exceed its scope — enforced today by the per-agent tool lists each agent is constructed with in application code. Externalizing that scoping to Cedar policies (Amazon Verified Permissions) is a production target and is not built in this prototype.

How Institutions Would Adopt

Ripple provides the settlement layer (XRPL) and developer tools (AI Starter Kit). The institution chooses their cloud, their AI model, their compliance vendor, and their custody model. This prototype shows the complete operational architecture on AWS.
